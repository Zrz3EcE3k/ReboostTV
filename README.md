# ReboostTV
1-Click Android, Google &amp; Fire TV optimizer. Debloat laggy TVs, block ads via DNS, clean hidden cache, run Wi-Fi/RAM/temp diagnostics, and type passwords from PC. Includes a live TV HUD overlay &amp; RAM Kill Switch. 100% transparent, open-source, zero bloat.
# ReboostTV
1-Click zrychlovač pro Android, Google a Fire TV (NakopniTV). Vyčistí balast, zablokuje reklamy přes DNS, uvolní RAM/cache, udělá rentgen Wi-Fi a teploty, přidá PC ovladač s psaním hesel i živý HUD panel a Kill Switch přímo do TV. 100% transparentní open-source bez balastu.
